# Art Deco civic work in progress

The five baseline sheets cover the existing four designs and five levels for each civic building. The silhouette scan found 148 close pairs between services, 150 close variant pairs and eight flat promotions.

Draft geometry for the Fanlight Library, postal exchange, sunburst court and signal hall lives in `src/game/designs/eraArt/deco/`. The playable Art Deco pack still uses its existing registrations. The treasury, era names, completed registrations, final rendered model reviews, city comparisons and checks remain open.
