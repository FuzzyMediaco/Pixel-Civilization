# Pixel Civilization mobile stores

The Apple and Google store apps bundle the game, its font, ten period packs and illustrated guide. Progress lives on the device. With an optional account, the same city and eligible purchases work across supported platforms. Both native clients request localized prices directly from the storefront. The account service verifies the transaction before granting access. Store updates are delivered through the respective store.

## Build

After installing the locked web dependencies, run `npm run build`, `node packages/store/prepare.mjs` and `node packages/store/catalog.mjs`. For a release, point PIXEL_WEB_DIST at an immutable snapshot of that web build for both packaging and verification. This produces the immutable web edition, the 16-product catalog and a StoreKit test configuration in `packages/store/generated`. The catalog is generated from the same product definitions as the game. Each native bundle records its source web edition in store-edition.json. The Android verifier checks every bundled asset against the edition and checks each page for its local billing bridge and script policy. Keep the ten era products and two premium modes non-consumable. Configure the four Pix plans in one Apple subscription group with Complete ranked first and Starter last. On Google Play give each subscription a recurring monthly base plan named `monthly`. Prices in the catalog are USD base prices; the app displays the storefront's actual price and currency.

- **Google Play.** With JDK 21, Android SDK 36, Build Tools 35.0.0 and Gradle 8.13, run `gradle -p packages/store/android bundleRelease`. Set `PIXEL_ANDROID_KEYSTORE` and `PIXEL_KEYSTORE_PASSWORD` to use the existing upload key. A manual build can use `PIXEL_BUILD_NUMBER` for a monotonically increasing version code. Run `node packages/store/verify-bundle.mjs <path-to-aab>` and `jarsigner -verify <path-to-aab>`. The upload format is the AAB. `assembleRelease` produces an installable APK for device QA. The store build uses the fixed origin and device save database of the earlier APK; signing must match when replacing an installed build.
- **Apple.** With Xcode 26 or newer on macOS, run `xcodegen generate` in `packages/store/ios`, then open `PixelCivilization.xcodeproj`. The iOS 16+ app launches its bundled islands on a fixed device-local origin and routes first-party API calls to the game host. In Xcode select the paid Apple development team, enable the In-App Purchase capability for the registered ID, choose the next build number, Archive for a device and distribute through Organizer. Keep the bundle ID `app.pixelcivilization.game` if available. On a simulator, choose `packages/store/generated/PixelCivilization.storekit` as the scheme's local StoreKit test configuration. Local StoreKit transactions exercise the native purchase UI; sandbox transactions test the authoritative server verifier.
- **Continuous integration.** For an exact copy of the published game, run the workflow manually with the full web edition fingerprint from its offline manifest. The release job checks every asset against that fingerprint. The Mobile store builds workflow compiles an Android AAB and runs the bundled game on iPhone and iPad simulators. Each screenshot waits for the requested street, skyline or Handbook to render. StoreKit purchase and restore tests run separately. An independent Mac builds the unsigned device archive, verifies its arm64 executable and compares all embedded assets with the reviewed edition. PR runs use no publisher secrets. Only a signed device archive exported for App Store Connect can be uploaded. The existing downloadable APK and Windows package have a separate updater and workflow.

## Listing

**App name** Pixel Civilization

**Apple subtitle** Build a living island city

**Play short description** Shape an island, connect its waterways and transit, and build across ten eras.

**Description**

Shape an island into a city you can watch at work. Lay a river through a neighborhood, span it with a bridge and follow a train from the market to the baths. Homes, food, water, jobs and transport all respond to the city you build.

Play in Original with the free modes. Explore the illustrated Handbook and turn models around in the Atlas to see how buildings grow. Optional historical and imagined era packs change the architecture of an existing island while preserving its streets, progress and economy. You can also purchase God Mode and Survival Mode individually.

Pix offers optional monthly plans with message allowances and a usage budget. The store shows what each plan includes and how much it costs before purchase. Active subscription access lasts through its paid period. You can restore purchases or manage renewal through your store.

**Store category** Games / Simulation. Secondary Apple category Strategy. The game contains stylized historical military elements and optional user-entered AI prompts. The publisher must review its actual content when completing ratings.

**Support and privacy** Use https://pixelcivilization.app/support.html, https://pixelcivilization.app/privacy.html and https://pixelcivilization.app/account-deletion.html. Enter a monitored publisher email in the store console. Apple subscriptions use Apple's standard EULA unless the legal publisher provides a custom agreement. [Standard EULA](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)

**Review notes** Start as a guest to build an island. Open the in-game store to see the localized price, sign in, purchase or restore. Reviewers need an isolated game account and a store sandbox tester for the purchase flow. Use More → Saves to inspect the island. Verify a paid appearance, a mode, a plan switch, expiry, offline access, restoration after install, cancellation and a refund on the submitted build. Record the exact tested build number. To test content reporting, open Pix, request advice and choose **Report this result** under the reply. The player can edit the excerpt before sending it. Authorized support staff review the private game database queue, ordered by creation date in the game_pix_reports table. Reports expire after 90 days. The app stores account email/user ID, game saves, purchase proofs and Pix usage. A player's selected AI provider receives the submitted prompt and game context. StoreKit/Play process card payments; the app does not store card numbers. Apple and Google each require their own disclosure form. [Apple review](https://developer.apple.com/app-store/review/guidelines/) · [Play Data safety](https://support.google.com/googleplay/android-developer/answer/10787469)

**Artwork and screenshots** The iOS workflow exports screenshots from iPhone Pro Max and 13-inch iPad simulator tests. Inspect them before upload. The Play feature graphic and 512px icon are in the listing folder. The two 1080 × 1920 Android screenshots were captured in the signed store wrapper by entering Pelican Reach and Copper Gorge through its island menu. Refresh them if the reviewed interface changes.
